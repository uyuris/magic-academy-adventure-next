# Cutover Plan

## Phase 1

Establish the new repository structure and governing policy documents.

## Phase 2

Import/copy source documentation and provenance snapshots from the old projects without editing the source projects.

## Phase 3

Normalize content/data/asset placement inside the new project.

## Phase 4

Rewire implementation work so new changes target only the new project.

## Cutover condition

The migration is considered cut over only when active implementation no longer depends on reorganizing or editing the old projects.
